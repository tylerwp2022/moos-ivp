# V2GPM development instructions

- `dev` is the source of truth for our project work. Target `dev` for contributions and push to `origin/dev`.
- Tyler owns `main`. Do not push to or merge into `main` unless the user explicitly requests it.
- The V2GPM component repositories also use `dev`. Commit and push component changes before updating their pinned commits in this repository.
- Submodule branch settings identify development branches; normal checkout and builds must still use the exact committed submodule pins.
- For project work histories, use `Acting agent: Cline/ChatGPT`. Record the actual human owner separately.
