# chat_tests.txt: the tests chat_driver.py types into the m2_alpha_llm
# chat pane, one block per test, in order. The ids follow chat_test.md.
# Keys:
#   say          the line typed into the chat; empty = no turn, pokes only
#   answer       y (default) or n for a proposal; none = no proposal is
#                expected (one that appears is declined and fails the test)
#   before_answer a line typed while the proposal waits, before answering
#                (the tree / steps read-back)
#   plan_answer  y or n typed when a running plan's Ask appears
#   poke         VAR=value posted on the shoreside before the line
#   wait         VAR = VALUE, or VAR alone: a post NEWER than the test's
#                start must appear (repeatable, all must be met)
#   timeout      real seconds to wait for the waits (default 120)
#   turn_timeout real seconds for the model's turn (default 240)
#   settle       seconds to let the log catch up before grading (default 4);
#                also the observation window for a check with no wait
#   check        one of (expect means the same; observe in front of any
#                check records the outcome without failing the test):
#     no_proposal | proposal | proposals N
#     tool NAME[|NAME]         a tool call named one of these
#     no_tool
#     target VNAME             a tool call aimed at that vehicle or team
#     head_for VNAME           the proposal reads "run_plan for VNAME:"
#     no_probe                 no run_plan with a junk tree
#     tree_has TEXT            the run_plan tree contains TEXT
#     no_collision [A [B]] | collision [A [B]]
#     no_near_miss [A [B]] | near_miss [A [B]]
#     reply_sentences <= N     the last plain reply's sentence count
#     reply_asks               the reply contains a question mark
#     reply_contains TEXT | chat_contains TEXT | proposal_contains TEXT
#     state VAR VALUE          the last post of VAR in the window
#     min_range A B >= N       closest approach of two boats, meters
#     no_truncation            no "cut off at max_tokens" reply
#     latency <= N             every model request under N real seconds
# Three boats: abe (0,-20), ben (30,-20), cal (-30,-20), heading south.
# Warp 10 headless, 5 with the viewer. Turn alerts on before Phase 5
# (test 5.0 does).
