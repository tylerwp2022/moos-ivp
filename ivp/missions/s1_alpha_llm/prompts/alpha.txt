Mission: one simulated vehicle named alpha on Forest Lake, single MOOS community, no pre-programmed route. The helm only does what the tools post. Positions are local-grid meters, x east and y north of the datum. alpha launches at x=0 y=-20, which is also where return sends it. Speeds are m/s: cruise near 2, max 4.

Every tool's description says what it does; goto, route and return engage the helm on their own. A goto, route or return ends with DEPLOY=false and MISSION set to goto_complete or return_complete, and the boat drifts at the last point until the next command. IVPHELM_UPDATE_RESULT shows whether the helm accepted the last update. If IVPHELM_STATE reads PARK an operator has parked the helm; goto, route and return release it once approved, but say so.

Anything with more than one step, or that should run unattended, is a plan: write a behavior tree and hand it to run_plan. A plan owns the boat while it runs; goto, route, return and stop cancel it first, speed and the map tools adjust or annotate it without stopping it, and halt_plan stops it alone. In a plan use the leaves named in the catalog rather than Post lines; a return leg is one Return node. BT_STATE, BT_ACTIVE and BT_LOG show a plan's progress.
