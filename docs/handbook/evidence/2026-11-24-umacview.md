# November 24 uMACView validation

Timeo Williams ran the Alpha reference scenario in Ubuntu 24.04 on WSL2. Both viewers were built from [the viewer and launcher changes](https://github.com/tylerwp2022/moos-ivp/commit/9ab39637c26e23cd77a60ed0e159e29da55c0f9e) against the pinned MOOS build. The other mission binaries came from the November 20 validation build. The [source manifest](source-manifest-2026-11-24-umacview.json) records the tested source and submodule pins.

The isolated GUI run used the local scripted endpoint. The equivalent PowerShell command is below.

```powershell
.\scripts\wsl\Project.ps1 -Action Demo -ChatViewer umacview -Port 20943
```

| Operator inputs in uMACView | Observation in the Alpha MOOS log |
|---|---|
| `setup smoke goto`, then `n` after `awaiting_confirm` | The agent recorded the decline. No waypoint update from pLLMAgent was logged. Alpha's `NAV_X` remained 0. |
| `setup smoke goto`, then `y` after `awaiting_confirm` in a fresh run | The agent posted one `WPT_UPDATE` for `(20,-20)`. Alpha's `NAV_X` exceeded 3. |

Both windows opened on the same MOOSDB. A separate chat exchange returned the scripted reply, and Tab completion followed by Enter switched the agent from execution to planning. The six installed self-test suites and all four headless Alpha checks also passed.

A late uMACView session rendered local and per-vehicle plan lines. After forced disconnection and reconnection, its transcript stayed the same and the draft posted only after Enter. The chat toggle, font shortcut, divider, realmcast layout, and interrupt publication were checked on the virtual display. The default pMarineViewer profile still submitted chat and received the scripted reply.

The run evidence includes the generated `alpha.moos` and the two Alpha `.alog` files. Use `LLM_CHAT_IN`, `LLM_STATUS`, `LLM_TOOL_RESULT`, `WPT_UPDATE`, and `NAV_X` to compare runs. A logger can record copies of the same MOOS message. Count distinct messages by timestamp, variable, source, and value.

An independent MIT run and live WIRE verification remain pending.
